0 / 6
▼

02Set correct ownership: sudo chown username:hpcinterns /home/username
03Create a shared /scratch dir and apply sticky bit: sudo chmod 1777 /scratch
04Test that another intern user cannot enter /home/otherintern — expected: Permission denied
05Set a file ACL on a project folder: sudo setfacl -m u:username:rx /projects

SSH Configuration & Key-Based Authentication
Day 4–5 · ~1.5 hours · OpenSSH / sshd_config
0 / 6
▼
01Generate SSH key pair on your client machine: ssh-keygen -t ed25519 -C "intern@pgcv"
02Copy public key to the server: ssh-copy-id username@server-ip
03Test key-based login — confirm no password prompt appears
04Edit /etc/ssh/sshd_config: set PermitRootLogin no and PasswordAuthentication no
05Restrict SSH access to interns only: add AllowGroups hpcinterns
06Restart SSH daemon and verify: sudo systemctl restart sshd && sudo systemctl status sshd
